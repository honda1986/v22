# v22 — データ置き場と検証の場所

競艇(ボートレース)のデータ収集・分析・モデル学習をするリポジトリ。
**アプリ本体は別リポジトリ [boatrace-appV23](https://github.com/honda1986/boatrace-appV23) にあります。**

分けている理由は、このリポジトリが80MB近くあり、
同居させると GitHub Pages のビルドが10〜30分かかってしまうため。

---

## データはここにあります

| 場所 | 中身 | 件数 |
|---|---|---|
| `raw/` | オッズ(3連単120通り)・着順・払戻・出走表 | 911日 / 137,107レース |
| `tokuten/` | 今節得点率・節内順位・今節ST・コース別成績 | 816日 |

どちらも `YYYYMMDD.json.gz` で1日1ファイル。2023年5月〜。

### raw に入っているもの

```
odds      3連単120通りのオッズ(締切時)
combos    120通りの組番("1-2-3" の並び)
hit       的中組    pay_3t  払戻
entries   枠番・級別・年齢・体重・F数・平均ST
          全国勝率/2連率・当地勝率/2連率・モーター2連率・ボート2連率
          展示タイム・course_in(本番進入)・rank(着順)
weather   気温・風速・波高・水温 ★ 全部 None。取れていません
```

**`course_in` は本番の進入コースです。** 学習に使うと結果を先に見ることになるので
禁止。過去に2回これで「回収率146%」という幻の結果が出ています。

**`weather` は空です。** `backfill.py` に取得処理はありますが、
オッズページを見ているため一度も値が入っていません。

### tokuten に入っているもの

```
tokuten   今節得点率     rank   節内順位     genten  減点
st_setsu  今節の平均ST   runs   各走の着順
c_win / c_ren3 / c_st    コース別(直近6ヶ月)の1着率・3連率・ST
n_win / n_2ren / l_win / l_2ren / m_2ren   勝率など
```

**決まり手は入っていません。** uchisankaku のページには載っていますが、
表の構造が他と違うためパースしていません。

## 毎日の収集

`.github/workflows/collect.yml`

JST 3:00 に自動で走ります。手動でも回せます。
**保存済みの日は飛ばす**ので、何度実行しても安全。

```
Actions → 毎日のデータ収集 → Run workflow
  days   直近何日ぶんを見るか(既定5)
  start/end  古い期間を埋めたいとき
  force  保存済みも取り直す(項目を増やしたとき)
```

`raw` を先に取り、それを索引にして `tokuten` を取ります(順番が大事)。

### 検証(全部 Colab で実行)

| ファイル | 何を測ったか | 結果 |
|---|---|---|
| `yosou_check.py` | 本命が1号艇でないレース | ゼロ |
| `yosou_check3.py` | レース選別(確率合計) | 的中率は上がるが回収率は平ら |
| `yosou_shikii.py` | 買い目の絞り方(点数 vs 確率) | **確率5%以上が良い** |
| `yosou_bunpai.py` | 資金配分3通り | 回収率は動かない。ばらつきだけ変わる |
| `yosou_haraimodoshi.py` | 払戻の水準で絞る | 15,000〜20,000円が良い |
| `yosou_x15.py` / `yosou_x15b.py` | 上の追試(交互作用) | 2条件は独立して効く |
| `yosou_icchi.py` | モデルと市場の一致度 | ゼロ |
| `yosou_wariyasu.py` | 割安舟券(中日スポーツの記事) | 否定された |
| `yosou_2t.py` | 2連単 | EVを上げるほど下がる |
| `tonari.py` | 内側の艇との差 | **モーターだけ z=4.9。ただし0.37pt** |
| `tokuten_analyze.py` | 得点率・準優ボーダー | ゼロ |
| `tokuten_racer.py` | 選手ごとの反応差 | 存在しない(過分散0.79) |
| `kishou_check.py` | 気象データ | 全部空だった |

### 到達点

```
勝負レース(上位8組の確率合計 ≧ 0.553)
  × 買い目は予想確率5%以上
  × 払戻が1万円あたり15,000〜20,000円
→ 1,333レースで 的中率53.5% / 回収率89.6%(誤差±2.3%)
```

**100%は超えません。** 17回試して、超えるものは1つも見つかっていません。

## 注意

- `course_in` `tenji`(展示タイム) `odds` は学習に使わない
- 検証は必ず学習に使っていない期間(2025-03-14以降)で
- 誤差±とz値を必ず出す。|z|が3未満は採用しない
- 年度がそろって同じ符号でなければ採用しない
