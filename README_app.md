## 動き

1. uchisankaku から当日の出走表を取る(1場1リクエスト)
2. 48特徴量を組んで、1着→2着→3着を順に予測
3. 3連単120通りの確率を作る
4. 候補レースは boatrace.jp から3連単オッズを取る
5. 買い目を作り、勝負レースを確定する
6. ntfy に通知を予約する
7. 締切後は払戻金一覧(1リクエスト)から結果を入れる

`yosou/data.json` に全部入ります。画面はこれを読むだけ。

### 勝負レースの条件

```
① 上位8組の確率合計 ≧ 0.553          全体の約10%
② 確率5%以上の組を払戻均等で買って、
   1万円あたりの払戻が15,000〜20,000円
```

**実測(34,018レースで検証): 1,333レースで的中率53.5% / 回収率89.6%**

回収率は100%を超えません。的中を楽しむための道具です。

### 通知

ntfy に**2回**予約します。予約はキャンセルできないため。

```
1回目「勝負(仮)」 見つけ次第すぐ。朝のオッズなので金額はあてにならない
2回目「勝負」     締切30分前ごろのオッズ。こちらを使う
```

`NTFY_TOPIC` を Settings → Secrets に登録しておく必要があります。

## 使っている情報・使っていない情報

| 使う(前日〜当日朝に確定) | 使わない(直前情報) |
|---|---|
| 枠番・級別・年齢・体重・F数 | **オッズ**(判定にだけ使用) |
| 全国勝率 / 当地勝率 | **展示タイム** |
| モーター2連率 / ボート2連率 | **進入コース** |
| 平均ST | 気象・安定板 |
| 今節得点率・節内順位・今節ST | |
| コース別1着率 / 3連率 / ST | |

**進入コースは絶対に学習に使いません。** raw に入っているのは本番進入なので、
使うと結果を先に見ることになります。過去に2回これで
「回収率146%」という幻の結果が出ました。

## 主な定数(`yosou.py` の上の方)

```python
SHOBU_TH = 0.553        勝負レースの閾値(上位8組の確率合計)
                        0.518=上位20% / 0.582=上位5%
BUY_P = 0.05            この確率以上の組を買う
PAY_LO, PAY_HI = 15000, 20000   払戻(1万円換算)の範囲
NOTIFY_BEFORE = 5       締切の何分前に通知するか
FINAL_LO, FINAL_HI = 22, 38     本命の通知を予約する窓
ODDS_MAX_AGE = 12       オッズがこれより古ければ取り直す
```
